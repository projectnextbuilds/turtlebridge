# Security Policy

## Supported versions

TurtleBridge is pre-release software. Security fixes are applied to the latest code on `main`; no released version is currently supported.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature when it is available for this repository. If it is unavailable, contact the repository owner privately before publishing technical details.

Do not open a public issue containing an exploit, signing material, controller serial number, full USB registry dump, or other sensitive system information. Include the smallest reproduction needed, the potential impact, and whether the issue requires a physical device or local access.

You should receive an acknowledgement within seven days. Timelines for validation and remediation depend on severity and reproducibility.
